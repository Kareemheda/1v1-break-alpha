# 1v1 Break (alpha)

A two-player card duel: you against the computer. Pick two fighters, then win the duel, break their chains and land the Killing Blow.

**Play:** https://kareemheda.github.io/1v1-break-alpha/

This is an early test version (alpha): rules and visuals are still changing. It runs in any web browser on a computer; nothing to install.
